# Documentation epartim-v2

Cette documentation sert de contrat de reconstruction pour le projet `epartim-v2`.

Elle ne remplace pas le code. Elle fixe les decisions metier et techniques qui
doivent guider les migrations, les modeles Lucid, les services Adonis et les
tests.

## Sources de travail

Les docs synthetisent les documents fonctionnels du prototype et les choix
techniques du projet Adonis existant.

Les documents repris du prototype sont renommes et organises comme des docs v2 :
ils doivent etre consideres comme des specifications de developpement, pas comme
un lot de tickets importe.
