# Acteurs et acces

Ces documents decrivent le modele commercial, les roles, les perimetres
d'acces, les partenaires et les regles de commissionnement qui structurent
`epartim-v2`.

## Decisions principales

- Le cabinet est l'organisation commerciale de base.
- Le reseau regroupe optionnellement des cabinets.
- Le distributeur est un role utilisateur, pas une table dediee.
- Les roles d'acces sont distincts des codes Amundi exportes.
- Les corrections commerciales ne reecrivent pas automatiquement l'historique
  des commissions.
