# Frais du contrat

## Objectif

Construire l'etape Frais du contrat pour gerer l'offre, la grille tarifaire, les frais d'ouverture, les droits d'entree et le porteur des droits.

## Perimetre fonctionnel

- Choix de l'offre.
- Acces a la grille tarifaire.
- Frais d'ouverture de dossier.
- Droits d'entree.
- Porteur des droits : entreprise ou salarie.

## Regles importantes

- Les frais d'ouverture de dossier peuvent etre nuls.
- Le paiement n'est pertinent que si un montant positif est du.
- Les droits d'entree sont portes uniquement par l'entreprise ou par le salarie.
- Les droits d'entree sont une condition du contrat de l'entreprise, pas une simple valeur derivee de l'offre.

## Definition de done

- L'offre est choisie.
- Les frais d'ouverture sont saisis.
- Les droits d'entree sont bornes et sauvegardes.
- Le porteur des droits est explicite.
