## Decisions principales

- Le parcours BSE est separe de l'entreprise Amundi finale.
- La souscription conserve son createur applicatif et son rattachement
  commercial.
- Le dossier documentaire est distinct du dossier Amundi.
- Les actions sensibles restent reservees aux roles internes autorises.
- Une transmission Amundi reussie ne complete pas seule la souscription.
