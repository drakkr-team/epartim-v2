# Formalisme mise en place

## Objectif

Construire l'etape Formalisme mise en place avec les modes DUE, CSE et ratification deux tiers, les personnes a renseigner et les documents associes.

## Perimetre fonctionnel

- Decision unilaterale employeur.
- Mise en place CSE.
- Ratification deux tiers.
- Signataire CSE.
- Membres CSE.
- Salaries signataires.
- Documents associes aux dispositifs et modes.

## Regles importantes

- DUE ne demande ni salaries signataires ni membres CSE.
- En mode CSE, le signataire CSE DocuSign est une personne dediee.
- Les membres CSE servent a alimenter le proces-verbal CSE.
- En ratification deux tiers, les salaries sont destinataires de signature avec le representant legal.
- Chaque document de ratification deux tiers part dans sa propre enveloppe.

## Definition de done

- Le mode de mise en place est choisi par dispositif.
- Les personnes attendues sont demandees selon le mode.
- Les documents associes sont determines.
- Les erreurs de formalisme bloquent la validation de l'etape.
