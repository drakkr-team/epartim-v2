# Profil utilisateur hors admin

## Objectif

Afficher les informations du compte utilisateur hors admin sans permettre la modification de l'email.

## Perimetre fonctionnel

- Page profil accessible aux utilisateurs connectes.
- Affichage du nom.
- Affichage du prenom.
- Affichage de l'email.
- Affichage du telephone mobile si disponible.
- Affichage du role metier.
- Affichage du cabinet et du reseau si disponibles.
- Affichage des informations utiles au contexte distributeur.

## Regles importantes

- Le profil est une page de consultation dans le premier cycle.
- L'email n'est pas modifiable par l'utilisateur.
- Les rattachements cabinet et reseau ne sont pas modifiables par l'utilisateur.
- Les roles ne sont pas modifiables par l'utilisateur.
- Le changement de mot de passe depuis le profil est hors perimetre initial.

## Definition de done

- L'utilisateur peut consulter son profil.
- Les informations affichees correspondent au compte connecte.
- Aucune action ne permet de modifier l'email.
- Aucune action ne permet de modifier les rattachements ou le role.
